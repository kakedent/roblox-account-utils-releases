# Roblox Account Utils
By 1kakeden.

A small Windows app for organizing Roblox accounts, keeping sign-ins separate, launching accounts in a queue, and sharing window assignments with Swordburst 2 Controller.

## Download
Get the Windows x64 ZIP from the [latest release](https://github.com/kakedent/roblox-account-utils-releases/releases/latest), extract it, and run **RobloxAccountUtils.exe**. Keep the included files together. Microsoft Edge WebView2 Runtime is required.

Add accounts, sign in, save your game links, and click **Launch checked accounts**. Use **Presets…** to save graphics/FPS/display defaults and **Set preset…** to assign them to accounts.

See [release notes](https://github.com/kakedent/roblox-account-utils-releases/releases) for changes.
