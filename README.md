# Roblox Account Utils

**By 1kakeden · Windows 10/11 x64**

I publish compiled downloads for Roblox Account Utils here. Application source is maintained privately.

## Download

Open **Releases**, select **v1.0.0** or a newer release, and download **Roblox_Account_Utils_v1.0.0_win-x64.zip** from its assets. Extract the entire ZIP and run **RobloxAccountUtils.exe**. Keep the included files and folders together. **SHA256SUMS.txt** contains the download checksum.

GitHub's automatic **Source code** archives contain this public repository's documentation, not the application source or the runnable download.

Embedded sign-in windows require the Microsoft Edge WebView2 Runtime. Saved account profiles and sign-in sessions remain local to the computer. Existing profiles are preserved.

This is an unofficial, unsigned utility, not affiliated with Roblox. Game and server rules apply.
